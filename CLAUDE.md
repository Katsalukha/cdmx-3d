# cdmx-3d

Stylized 3D viewer for CDMX neighborhoods, built from OpenStreetMap data.
Default location: **Plaza Luis Cabrera** (19.41633, -99.15955), Roma Norte.

## Tech stack

- Three.js **r128** loaded from cdnjs CDN. No build step, no package manager.
- Vanilla JS in a single IIFE, served as static files.
- Local dev: `python3 -m http.server 8000` from project root → `http://localhost:8000`.
- Production: GitHub Pages serves the repo root at https://katsalukha.github.io/cdmx-3d/.
  Same paths work locally and on Pages — no build, no deploy step beyond `git push`.
- OSM data is pre-fetched from Overpass into `data/*.json` and loaded at runtime.
  Live geocoding (Nominatim) + Overpass fetch is also available from the search box
  for arbitrary addresses (requires HTTPS or localhost — fails under `file://`).

## Layout

```
index.html           # the viewer (HTML + CSS + JS, single file)
data/
  *.json             # one pre-fetched OSM dataset per location
  manifest.json      # ordered list of locations for the dropdown
scripts/
  fetch_osm.py       # Overpass fetcher; writes data/<slug>.json
.nojekyll            # disables Jekyll on GitHub Pages
CLAUDE.md            # this file
```

## OSM data schema (data/*.json)

Compact keys to keep file sizes down. Generated by `scripts/fetch_osm.py`.

```json
{
  "c": [center_lat, center_lon],
  "r": radius_m,
  "name": "Plaza Luis Cabrera",
  "secondary": "Roma Norte · Cuauhtémoc, CDMX",
  "e": [
    { "t": "n", "i": 12345, "lat": 19.4163, "lon": -99.1595 },
    { "t": "w", "i": 67890, "n": [12345, ...], "tags": { "building": "yes", ... } }
  ]
}
```

Whitelisted tags: `building`, `building:levels`, `building:material`, `height`,
`highway`, `name`, `leisure`, `landuse`, `natural`, `amenity`.

## Visual aesthetic

- Background **bone** `#f1e8d3`, ground `#ebe1c6`, ink `#2a201a`.
- Building palette: 16 warm earth tones (terracotta, adobe, rust, sand) hash-assigned per OSM ID.
- Color-override palette (12 swatches): Rosa Barragán, Azul cobalto, Amarillo Frida,
  Cempasúchil, Jacaranda, Verde aguacate, Rosa mexicano, Turquesa, Terracota, Adobe,
  Pulque, Carbón.
- Fonts: **Fraunces** (display + body, italic accents), **JetBrains Mono** (UI chrome,
  numbers, eyebrows). Loaded from Google Fonts.
- All UI text in Spanish ("Aplanando fachadas", "norte arriba", "buscando dirección…").
- Roads `#463d33`. Parks `#6e7c4d`. Trees: ficus `#2f5a32`, jacaranda `#7a5ea8`,
  olivo `#8aa080`.

## Building rendering

- **Geometry**: `THREE.ExtrudeGeometry` per polygon. Roof + base get a flat color cap;
  walls get a tiled procedural canvas texture (1 tile = 3m × 3m, 256px).
- **Heights**: `tags.height` → `tags['building:levels'] × 3.3m` → fallback
  `7 + hash(id) × 6` (≈ 7–13 m).
- **Wall materials** (4): `plaster` (aplanado), `brick` (ladrillo), `concrete`,
  `stone` (cantera). Auto-detected from `building:material`; falls back to
  weighted hash (~65% plaster, 13% brick, 13% concrete, 9% stone).
- **Window variants** (5): classic dark wood + blue glass; black metal + cool gray;
  white painted; wood + folded shutters; dark frame + iron *rejas*.
  One variant per building, hash-picked. (material × variant) textures cached lazily.
- **Doors**: placed on the longest polygon edge for buildings with area ≥ 15 m² and
  height ≥ 2.5 m. 6 styles (wood, wood_dark, wood_glass, metal, metal_painted, glass);
  commercial/retail/restaurant tags bias toward glass/metal.
- **Tinacos** (rooftop water tanks): placed on plain buildings with area ≥ 25 m² and
  height ≥ 4 m. Skipped on landmark archetypes.
- **Edge lines** drawn at 30° angle threshold for crisp silhouettes.
- **Per-building overrides**: clicking a building opens an inspector with palette and
  material pickers; overrides keyed by OSM way ID, lost on location change (intentional —
  IDs don't translate across cities).

## Cars (animation)

Schematic vehicles drive along the road network. The whole fleet is one
`THREE.InstancedMesh` (one geometry, one material, per-instance color via
`instanceColor`) — single draw call regardless of count. Geometry is a side-profile
silhouette extruded across the car width (~30 triangles per car). No wheels; the
body sits ~0.2m above the road and the gap reads as ground clearance.

- 8 hash-picked colors (charcoal, off-white, burgundy, deep blue, olive, mexican-pink-taxi…).
- Density: ~35% of eligible roads, capped at 80 cars (`MAX_CARS`).
- Skip set: `footway`, `path`, `steps`, `cycleway`, `pedestrian`, `living_street`.
- Cars drive on the right side of their forward direction (Mexican traffic).
- Speed: 4–8 m/s per car (~14–29 km/h).
- Respawn: when a car reaches a road's end, it picks a fresh random road and re-enters
  at the entry edge.
- `frustumCulled = false` on the InstancedMesh (its bounding box is single-instance and
  centered at origin — would cull the whole fleet otherwise).
- `castShadow = false` to avoid multiplying the shadow-map cost by car count;
  `receiveShadow = true` so cars darken when passing under tall buildings.

## Path B landmark archetypes

Tag-detected building categories that get distinctive primitive geometry on top of
the standard extrusion. Keep low-poly: boxes, cylinders, triangles only — no curves
beyond cylinders. Reuse the cap material so per-building color tinting still applies.

| archetype  | tag trigger                                                | added geometry                       | status |
|------------|------------------------------------------------------------|--------------------------------------|--------|
| religious  | `amenity=place_of_worship`, `building=church\|chapel\|...` | gable roof + bell tower + cross      | done   |
| hospital   | `amenity=hospital`, `building=hospital`                    | red rooftop cross                    | done   |
| school     | `amenity=school`                                           | flagpole + Mexican flag (green/white/red) | done |
| civic      | `building=civic`, `amenity=townhall`                       | triangular pediment along long axis  | done   |
| retail     | `building=retail`, `shop=*`                                | striped red/cream awning over the door | done |
